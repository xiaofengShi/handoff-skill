范围 同机续接 GitHub 分享
Session 当前任务、关键决定、相关改动与下一步。 对方可获取的任务版本、输入与执行步骤。
Project 项目目标、结构、依赖、整体能力、维护方式与待办。 完整项目接手说明、固定版本、环境、验证与维护步骤。

“交接一下／换个对话继续”默认按 Session 处理；“项目交接／交接整个项目”会覆盖整体结构与维护方式。

交接正文默认跟随用户当前请求的语言；明确指定输出语言时，以指定为准。命令、标识符、路径和原始日志保持准确。

使用前了解这几件事。

输出会跟随我的语言吗？

会。交接正文与修改后的说明默认使用当前请求的语言；明确指定输出语言时优先遵从。命令、路径、标识符和原始日志保持准确。

接收者也要安装这个 Skill 吗？

不需要。分享文档本身应包含接手说明，以及接收者可访问的资料入口。

它会自动发布我的工作吗？

交接流程要求发布、推送或修改权限前获得明确授权；安装 Skill 不会授予这些权限。

项目需要私有数据怎么办？

交接应说明访问条件或缺少的依赖，不应嵌入密钥，也不能在必要输入尚未交付时声称对方已可运行。

支持哪些 Agent？

包中包含 Codex 元数据和标准 SKILL.md 指令。Skills CLI 可将其安装到支持的 Agent；执行行为取决于宿主。核心指令使用中文，要求按用户的语言输出。
