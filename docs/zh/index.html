使用前了解这几件事。

接收者也要安装这个 Skill 吗？

不需要。分享文档本身应包含接手说明，以及接收者可访问的资料入口。

它会自动发布我的工作吗？

交接流程要求发布、推送或修改权限前获得明确授权；安装 Skill 不会授予这些权限。

项目需要私有数据怎么办？

交接应说明访问条件或缺少的依赖，不应嵌入密钥，也不能在必要输入尚未交付时声称对方已可运行。

支持哪些 Agent？

包中包含 Codex 元数据和标准 SKILL.md 指令。Skills CLI 可将其安装到支持的 Agent；执行行为取决于宿主。核心指令使用中文，要求按用户的语言输出。
