The useful part of a conversation should survive the conversation.

A summary tells you what happened. A handoff also tells the next person where to begin, what was verified, and what is still missing.

Start with one skill.

Run the command, choose your agent, and ask for a handoff. The CLI installs to the current project by default; add -g for a global installation.

New session

New teammate

A few things to know.

Does the recipient need this skill?

No. A shared handoff should contain the instructions and accessible source references needed to continue.

Will it publish my work?

The handoff workflow requires explicit authorization before publishing, pushing, or changing access. Installing it does not grant that authorization.

What if the project needs private data?

The handoff should identify the access requirement or missing dependency. It should never embed credentials or claim a project is runnable while required inputs are unavailable.

Which agents can use it?

The package includes Codex metadata and standard SKILL.md instructions. The Skills CLI can install it to supported agents; behavior varies by host. The core instructions are in Chinese and request output in the user’s language.
